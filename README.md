# HelpDesk Pro

Sistema web de gerenciamento de chamados de suporte técnico, desenvolvido como projeto de estudo e portfólio, com integração entre frontend e backend.

## Sobre o projeto

O HelpDesk Pro permite cadastrar e consultar chamados de suporte técnico por meio de uma interface web integrada a uma API desenvolvida em Python.

O projeto foi criado para praticar desenvolvimento web, integração entre tecnologias, construção de APIs REST e persistência de dados em banco de dados.

## Funcionalidades

- Cadastro de chamados de suporte.
- Listagem de chamados cadastrados.
- Identificação do solicitante.
- Definição de prioridade.
- Acompanhamento do status do chamado.
- Armazenamento dos dados em banco SQLite.
- Integração entre frontend e backend utilizando Fetch API.
